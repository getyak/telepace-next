## 4. 本轮关键优化

### 真实性与分析

- 新增真实 Campaign evidence API，报告不再依赖 mock evidence。
- 分析 worker 每次从所有已完成访谈重建聚合结果，用 replacement event 清理旧洞察，避免无限追加和回放重复。
- 只接受能在受访者原话中精确匹配的逐字稿，丢弃模型伪造引用。
- 主题、风险和建议分离；建议只来自 analyst 明确 recommendation。
- 历史访谈覆盖率从 durable outline 还原，完成记录显示真实 100%。

### 访谈体验

- 协议解析兼容 action tag、JSON fence、裸 JSON 和 prose + JSON，控制载荷不进入用户文本。
- 服务端持久化当前问题、覆盖项和追问次数，强制按 guide 前进并遵守 `max_followups`。
- UI 展示当前问题、总问题、追问和完成度；实际时长来自访谈事件。
- fatal WebSocket 失败不再显示“答案已保存”的误导性文案。

### 登录与会话

- refresh cookie 改为根路径，middleware 和 layout 把 refresh-only 状态视为可续期会话。
- 发放/退出时兼容并清理旧 `/api/auth` 路径 cookie。
- OAuth 隔离和 Google 回调路径继续由集成测试覆盖。

### 报告、UI 与导出

- 动态研究标题、本地化生成时间、方法、样本量警告、匿名受访者标签和引用抽屉。
- Markdown 使用人类可读文件名，并与网页共享统一的 finding/citation 模型。
- PDF 隐藏桌面/移动导航和研究助手；章节标题、卡片、建议、附录均设置打印分页约束。
- 移动端 390×844 同意页和聊天页无横向溢出；弹窗支持焦点管理和 Escape。
- 清理全部前端 lint warning；设计颜色与 token 检查无漂移。
