# Frontend dependency security maintenance (T-703)

Next and eslint-config-next stay on 15.5.28; React stays on 18 and Tailwind stays on 3. The Next patch includes the image-optimization fix described in the [upstream advisory](https://github.com/vercel/next.js/security/advisories/GHSA-2464-fhr4-w9xw). The lockfile also updates compatible js-yaml, undici, brace-expansion, source-map-js, sharp, Vitest and Vite patches. Vite is an explicit development peer so pnpm does not reuse the older vulnerable peer resolution.

`braces@3.0.3` has no released fix for [GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm); [upstream issue 70](https://github.com/micromatch/braces/issues/70) describes the unbounded recursive AST walkers. Our local patch caps parsed brace/parenthesis nesting and AST traversal depth at 100, including cyclic node/parent inputs. Patterns within the bound retain their existing behavior. It is a local mitigation, not an upstream release or a version change.

`pnpm install` runs the installed-package regression gate. The gate binds the exact patch SHA-256, pnpm lock hash, installed JavaScript hashes, and every current dependent's actual package resolution. It tests ordinary patterns, quotes/escaping, nesting boundaries, deep/cyclic ASTs, and tampered files. A patch, package-version, resolution-path or source change requires deliberate review of those bindings.

`pnpm audit:security` retains and prints the raw registry response. Its high/critical gate recognizes only this advisory for exactly version 3.0.3 on the reviewed dependency paths, after the source and regression checks pass. Every unknown/unmitigated high or critical advisory fails. Registry/process errors, malformed or incomplete responses fail. CI archives the raw response even when the audit gate fails. The raw `pnpm audit` still reports the patched braces version as high; it is not described as clean or suppressed in npm configuration.

The targeted `postcss-selector-parser@6.1.4` override uses 7.1.7 because the [upstream change log](https://github.com/postcss/postcss-selector-parser/blob/main/CHANGELOG.md) records the flat-selector CPU fix in 7.1.6 and no 6.x backport is published. This is the sole transitive major override. Actual Tailwind 3 preset typography, `@apply`, responsive/hover/group/arbitrary variants, and the nested-selector consumer compile in regression tests; their CSS output is compared against the pre-override baseline. The existing audit threshold remains high; no moderate findings are hidden.

CI uses Node 22.23.2 because the existing jsdom 29/Vite 8 toolchain requires a newer runtime than Node 20. No lint, typecheck, test, token/design, build or backend assertion is skipped by this change. No production deployment is configured or performed.
